YOUR JAVA SANDBOX

Small scope. Real execution.

Paste a Java method or a class Solution. The trace executes your code locally and records each declaration, statement, loop update, condition, call, and return. A step shows the state after the highlighted instruction.

Supported in this version

int, long, boolean, char, String, arrays, if/else, while, for, break/continue, ternaries, and helper method calls. Collections: HashMap, HashSet, ArrayList, Stack and basic ArrayDeque operations. Utilities: Math.min/max/abs, Arrays.sort/fill/equals/asList.

Inputs are a JSON object matching the entry method’s parameter names. The first method is the entry point. Use small inputs: up to 128 elements, 4,000 trace steps, and 32 call frames.

Execution model

This is a teaching interpreter, not a JVM debugger. Stack and heap are logical snapshots; library calls are one step. No threads, streams, lambdas, custom object types, exceptions, GC, or Java bytecodes. Use integer arithmetic within the safe numeric range; full JVM overflow and floating-point semantics are outside this version.
