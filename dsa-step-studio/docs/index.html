YOUR JAVA SANDBOX

Small scope. Real execution.

Paste a Java method or a class Solution. The trace executes your code locally and records each declaration, statement, loop update, condition, call, and return. A step shows the state after the highlighted instruction.

Supported in this version

int, long, boolean, char, String, double, matrices, ListNode/TreeNode/TrieNode fields, bitwise XOR/AND/OR, arrays, if/else, while, for, break/continue, ternaries, and helper method calls. Collections: HashMap, HashSet, ArrayList, Stack and ArrayDeque operations and integer PriorityQueue min-heaps. Utilities: Math.min/max/abs, Arrays.sort/fill/equals/asList.

Inputs are a JSON object matching the entry method’s parameter names. The first method is the entry point. Use small inputs: up to 128 elements, 6,000 trace steps, and 32 call frames.

Linked inputs and operation drivers

Lists accept an array, or {"values":[3,2,0],"cycle":1}. Shared tails use {"values":[4,1],"tail":"join"} plus a top-level "shared":{"join":[8,4,5]}. Trees use level-order arrays with null children. LC 303, 901 and 208 use visible method drivers for their sequences of operations.

Execution model

This is a teaching interpreter, not a JVM debugger. Stack and heap are logical snapshots; library calls are one step. No threads, streams, lambdas, arbitrary custom classes, exceptions, GC, or Java bytecodes. The three teaching node types are built in. Decimal arithmetic supports the floating-point binary-search examples; exact JVM integer overflow and long precision beyond JavaScript safe integers are outside this version.
